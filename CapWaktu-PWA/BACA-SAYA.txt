CAPWAKTU - VERSI YANG BISA DI-INSTALL
=====================================

Unggah SEMUA isi folder ini (index.html, sw.js, manifest.webmanifest,
folder "assets" dan folder "icons") ke hosting HTTPS.

NETLIFY (paling mudah)
1. Buka app.netlify.com dan login.
2. Situs baru: Add new site > Deploy manually, lalu seret folder ini.
   Memperbarui situs yang sudah ada: buka situsnya > tab Deploys >
   seret folder ini ke kotak "Drag and drop your site output folder here".
3. Buka alamat situs (https://NAMA.netlify.app) di Chrome Android,
   ketuk tombol kuning "Pasang", izinkan Kamera dan Lokasi.
4. Setelah memperbarui: tutup aplikasi di HP lalu buka lagi (1-2 kali)
   agar versi baru aktif.

GITHUB PAGES (alternatif gratis)
1. Buat repository baru, mis. "capwaktu" (Public).
2. Klik "uploading an existing file", tarik semua isi folder ini
   (termasuk folder assets dan icons), lalu "Commit changes".
3. Settings > Pages > Deploy from a branch > main > / (root) > Save.
4. Buka https://NAMA-AKUN.github.io/capwaktu/ di Chrome Android,
   ketuk tombol kuning "Pasang".

FITUR
- Waktu manual: Atur > Waktu > Manual.
- Bagikan template ke rekan: Atur > Bagikan. Rekan cukup membuka linknya.
- Simpan otomatis: foto langsung masuk folder Download di HP
  (tampil di Galeri / Google Foto, album "Download").
